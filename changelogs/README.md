# Changelog

本目录记录本仓库相对上游 [`pbodq2/OpenWRT-W1700K-XR1710G`](https://github.com/pbodq2/OpenWRT-W1700K-XR1710G) 的所有自定义改动，便于上游更新时判断冲突、迁移或回滚。

## 约定

- 文件名：`YYYY-MM-DD_NN_slug.md`（同一天多批改动用 `_01`、`_02` 递增）。
- 每批改动一个文件，不要追加到旧文件里。
- 每个文件至少包含：
  - **上游基点**：改动基于的上游 commit。
  - **背景 / 原因**：为什么改。
  - **改动内容**：涉及文件与关键 diff 摘要。
  - **验证方式**：如何确认生效。
  - **回滚方式**：如何撤销。
- 纯上游同步（没有自定义改动）也建议记一条，写清同步到的 commit。
