# 2026-10-31 — XR1710G 改用 airoha-fancontrol

## 上游基点

- `22d02fe`（工作树 `81742af`）

## 参考

`naoki66/ImmortalWrt-for-Gemtek-brightspeed` 的 `target/linux/airoha/image/an7581.mk`：

- `gemtek_xr1710g-common` 的 `DEVICE_PACKAGES` 只包含 `kmod-hwmon-nct7802`，**没有**强制任何 fancontrol 包
- 风扇 UI 由用户软件包列表选择，常用的是 `app_airoha` feed 里的 `luci-app-airoha-fancontrol`

两个 fancontrol 包都通过 `nct7802` hwmon 控制风扇，接口和默认曲线基本一致；区别主要是包名、翻译和命名。XR1710G 用 `airoha-fancontrol` 更符合参考仓库的用法。

## 改动

### 1. XR1710G device profile

`target/linux/airoha/image/an7581.mk`，仅修改 `gemtek_xr1710g-ubi` 的 `DEVICE_PACKAGES`：

```diff
-		    luci-app-w1700k-fancontrol \
+		    luci-app-airoha-fancontrol \
```

W1700K profile 不变，仍使用 `luci-app-w1700k-fancontrol`。

### 2. seed

重新加入：

```text
CONFIG_PACKAGE_luci-app-airoha-fancontrol=y
CONFIG_PACKAGE_luci-i18n-airoha-fancontrol-zh-cn=y
```

## 验证

本地 `make defconfig`：

```text
CONFIG_PACKAGE_luci-app-airoha-fancontrol=y
# CONFIG_PACKAGE_luci-app-w1700k-fancontrol is not set
```

121 个 seed 符号全部保留，无缺失。

## 注意

- 用同一个 seed 编 W1700K 时，profile 仍会带 `luci-app-w1700k-fancontrol`，与 seed 里的 airoha 版本冲突，需要单独调整。
- 上一轮 `41212372150` 使用 w1700k 版本，本次 push 后会被 concurrency 自动取消。

## 回滚

```sh
git checkout 81742af -- target/linux/airoha/image/an7581.mk
```

并把 seed 里的 airoha-fancontrol 两行换回 w1700k。
